03.3 — FOUNDER'S TOUCH

Built like a lab, run like a studio.

The floor is laid out in process order and everything rolls, so the room can be reset for a single part or a production run. Mixing is done by weight on a scale, under the same blue‑tape line the catalogue uses, and every batch is logged.

01Sealed grey floor, blue air lines, nothing on the ground
02Mixing by weight, not by eye, with the KLEEQ calculator
03Camera arm over the bench records every part before it ships
04Flammables, eyewash and first aid where the hand already is
03.4 — CURE & INSPECT

The quiet end of the room.

Every part is inspected under the light before it leaves. Batch, color, cure and operator are logged, so each finish is traceable back to the bench it came from.
